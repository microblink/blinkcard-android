BlinkCardSdkStrings

@Immutable
data class BlinkCardSdkStrings(val blinkCardScanningStrings: ScanningStrings, val blinkCardHelpDialogsStrings: HelpDialogsStrings, val blinkCardAccessibilityStrings: AccessibilityStrings) : Parcelable, SdkStrings

Data class contains all the strings used throughout the SDK. Default can be used to keep the original strings if only some of the elements are to be changed.

This class shouldn't be modified, but rather a new instance should be created and used in com.microblink.ux.UiSettings.sdkStrings.
